# 磁力计 Demo 上电与校准说明

## 上电前

1. 首次操作先拆下桨叶。
2. 飞机远离铁架、钢桌、扬声器、手机、磁铁、大电流电源线和通电电机。
3. 遥控器先开机，CH6 保持锁定，油门保持最低，CH5 保持关闭。
4. 连接 USB 虚拟串口并打开串口终端。固件不再使用蜂鸣器，所有状态都从该串口输出。
5. 校准时连同磁力计、飞控板和机架整体转动，不能只转磁力计模块。

## 每次上电的自动校准流程

本 Demo 没有把磁力计校准参数写入非易失存储器，因此每次重新上电都要校准一次。

| 串口提示 | 具体操作 |
|---|---|
| `[MAG] CAL REQUIRED...` | 保持 CH6 锁定和最低油门，等待约 4 秒。 |
| `[MAG] CAL START...` | 开始缓慢转动整机，依次绕 Roll、Pitch、Yaw 三个轴转动，使机头、机尾、左侧、右侧、顶部和底部分别朝向不同方向。 |
| `[MAG] CAL IN PROGRESS...` | 继续缓慢转动。该提示约每 2 秒出现一次，采集至少 20 秒、最长 90 秒。 |
| `[MAG] CAL VALIDATING...` | 继续缓慢转动约 10 秒，不要停下。 |
| `[MAG] CAL SUCCESS...` | 立即把飞机放到以电机平面为基准的水平硬质台面，保持锁定、最低油门和完全静止。 |
| `[MAG] READY...` | 磁力计参数已经放行，继续静置等待水平校准完成。 |
| `Level trim ready...` | 陀螺仪零偏学习和水平校准均已完成，可以进行无桨方向检查。 |

磁力计校准需要充分转动，水平校准需要完全静止。必须先完成磁力计校准，再放平静置；由于校准期间移动过飞机，通常还要等待约 40 秒才会出现 `Level trim ready`。

若出现 `[MAG] CAL FAILED...`，先排除周围磁性物体和大电流导线，再通过遥控器组合操作或串口命令重试。若出现 `[MAG] READ FAILED...`，检查 HMC5883L 的供电与 I2C 接线。

## 遥控器和串口命令

保持 CH6 锁定、油门低于 50，将 CH5 打开并持续 3 秒，可请求重新校准。出现 `[MAG] CAL START...` 后把 CH5 恢复关闭，再按上述流程转动整机。

也可以通过串口发送：

```text
MAGCAL   开始重新校准
MAGINFO  查看状态、样本数、方向覆盖和校准参数
MAGSTOP  中止当前校准
```

周期性的 IMU、姿态和气压计遥测已经关闭，串口只保留初始化信息、状态变化、故障、校准提示和主动查询结果，避免持续输出干扰控制循环。

## 起飞前检查

1. 必须依次看到 `[MAG] CAL SUCCESS...`、`[MAG] READY...` 和 `Level trim ready...`。
2. 发送 `MAGINFO`，确认 `MAG state:6` 且 `valid:1`。
3. 水平缓慢转动机头，Yaw 应连续变化且无突然跳变；转回原方向后应接近原值。
4. 分别小角度前倾、后倾、左倾、右倾，Yaw 不应大幅跳变。若倾斜时明显跳变，说明磁力计坐标映射仍不正确，不能起飞。
5. 正式拍摄前进行无桨电机测试，观察航向是否随油门明显偏移。若偏移明显，需要移动磁力计或重新布置电源线。

更换电池位置、移动大电流线、增加金属部件或改变磁力计安装位置后，需要重新校准。
