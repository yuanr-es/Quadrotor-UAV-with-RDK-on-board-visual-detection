# 发布检查清单（Release Checklist）

> 参见 TODOList.md §1、§10、§12、§13。发布前逐项确认，未通过不得出包。

## 1. 代码与构建

- [ ] Release 构建已关闭 Mock 定时器、测试设备、开发 URL、调试日志。
- [ ] 无明文密钥 / 签名口令进入仓库。
- [ ] `manifest.json` 权限逐项有对应功能与测试用例，删除无业务依据权限
      （`READ_LOGS`、`MOUNT_UNMOUNT_FILESYSTEMS`、`GET_ACCOUNTS`、`READ_PHONE_STATE`、`WRITE_SETTINGS`）。
- [ ] 已删除伪造的 `android.permission.USB_PERMISSION`（USB 授权由 `UsbManager.requestPermission()` 完成）。
- [ ] 广播接收器 / Activity / Service 明确 `exported` 属性。
- [ ] 所有单元测试通过（协议解析、坐标转换、状态机、store）。

## 2. 真机验收

- [ ] 每个目标 Android 大版本至少 1 台设备通过。
- [ ] 视频连续预览 30 分钟无崩溃、无持续内存增长、无明显绿屏/花屏。
- [ ] 拔插、授权拒绝、设备占用、供电不足、异常断流均有可解释处理。
- [ ] 前后台切换、锁屏、旋转、页面回收可正确释放/恢复资源。
- [ ] BLE 关闭、权限拒绝、超距断线、设备重启均进入安全状态。
- [ ] 摇杆控制 30 分钟无写队列堆积；抬手回中/安全值符合产品规则。

## 3. 性能指标（数值需与产品/硬件确认）

- [ ] 首帧时间 P50/P95 已记录。
- [ ] 端到端视频延迟已用可测量方法记录。
- [ ] 采集/渲染 FPS、丢帧率、最大卡顿时间已记录。
- [ ] 控制发送抖动、ACK 时延、失联检测时间已记录。
- [ ] CPU / 内存 / 温度 / 电量在 720p / 1080p 下已记录。

## 4. 交付物归档

- [ ] 签名 APK / HAP。
- [ ] 符号文件（mapping / so 符号）。
- [ ] 版本信息、versionCode、Git commit。
- [ ] 测试报告（见 `docs/technical-report-template.md`）。
- [ ] 硬件固件版本与依赖清单（SBOM / 许可证）。
- [ ] 隐私政策、用户手册、开发文档已更新。

## 5. 阻断发布的问题定义

以下任一出现即为阻断发布：

- [ ] 控制失效或误发。
- [ ] 状态假在线（数据过期仍显示「飞行中」）。
- [ ] 视频卡死无提示。
- [ ] 拔插崩溃。
- [ ] 资源无法恢复。
